# Подключение админки Firebase

Магазин использует Cloud Firestore. Товары хранятся в коллекции `products`; вход в панель выполняется через Firebase Authentication (email и пароль).

## Первичная настройка

1. В Firebase Console открой проект `my-shop-5eca0` и создай базу Cloud Firestore, если она ещё не создана.
2. В Authentication включи способ входа **Email/Password** и создай пользователя для владельца магазина.
3. Открой Firestore Rules, вставь содержимое файла `firestore.rules` и опубликуй правила. Не оставляй базу в тестовом режиме.
4. В Firestore Console создай коллекцию `Admins`. Создай документ с ID, равным UID пользователя из Authentication, и полем `active` типа boolean со значением `true`.
5. Открой `/admin` на сайте и войди с email и паролем этого пользователя. В панели можно добавлять, редактировать и удалять товары. Если коллекция `products` пустая, можно загрузить стартовый каталог.

До шага 4 пользователь может войти, но не сможет управлять товарами. Его UID появится на странице `/admin`.

## Поля товара

Каждый документ коллекции `products` содержит `name`, `category`, `price` (число), `color`, `image` (URL изображения), `tag` (строка, может быть пустой), а также временные метки `createdAt` и `updatedAt`.

Витрина читает каталог публично. Создавать, менять и удалять товары могут только пользователи, для которых документ `Admins/{uid}` содержит `active: true`.

## Корзина и избранное

Корзина и избранное авторизованного пользователя хранятся только в документе `userPreferences/{uid}`; клиент не сохраняет их в `localStorage`. Старые значения из прежней версии один раз переносятся в документ аккаунта, если он ещё не создан, а ключи затем удаляются из браузера. Правила разрешают читать и менять документ только его владельцу. Для неавторизованных посетителей изменения корзины и избранного действуют только до закрытия/перезагрузки страницы.

## Отзывы и пользователи

Новые отзывы о товарах (`reviews`) и магазине (`siteReviews`) создаются со статусом `pending` и не видны посетителям до одобрения. Администратор может одобрить, скрыть или удалить отзыв в панели `/admin`. Пользовательские профили хранятся в `users/{uid}` и создаются при входе пользователя; поэтому ранее зарегистрированные аккаунты появятся в списке админки после следующего входа на сайт.

## Локальная отправка заказов в Telegram

При запуске через `npm run dev` Vite также обслуживает `/api/send-telegram`. Для реальной отправки уведомлений задай серверные переменные окружения `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY`, `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Не добавляй эти секреты в клиентский код или репозиторий.
